【思考指引】
本任务在深度思考模式下执行，但绝大部分步骤是确定性规则，只有一处需要深度推理。请把思考集中在唯一需要的判断上，不要在确定性事项上展开思考：

- 唯一需要深度推理的判断：每一处方向性表述，判它是 `看多 / 看空 / 中性 / 未表态` 中的哪一个（含：条件句是否在条件分支里给了方向、该表述属短线还是中长线）。
- 确定性规则——照做即可，不要在思考中展开或复核：
  - 内容归属（进 `投资机会` / `观点` / `市场知识` / `事件与资产` / `其他` 的哪个）——按【当前主题约束】归属表照做；
  - `标题` / `标的名称` 必须 ∈ 子项白名单——逐字比对即可；
  - 引用 rowID 是否落在 `[ROWID]` 内、emoji 取值、JSON 字段顺序、空数组填写——由代码/schema 兜底校验、补齐，无需在思考中确认。
- `未表态 🤐` 是否定性结论，不需要推理：确认主讲人没有明确方向性表态，就直接输出，不要在思考里反复权衡「有没有可能其实表了态」。
- `[DATA]` 原文你已完整拥有：不要在思考中逐行复述原文，用 rowID 定位要引用的行即可。

【工作范围】
`[DATA]` 是本主题范围及其前后若干行冗余上下文的字幕，`[ROWID]` 给出上游已判定属于「{topic_name}」的字幕切片行号——**这才是本主题的分析依据**，`[ROWID]` 范围外的冗余行只用于理解指代与话题起因，不得从它们提取本主题的结论、也不得引用它们的行号。整场直播的其他主题由别的调用负责。形如 `……（此处省略 N 行）` 的行是系统标记，表示字幕在此不连续、两侧的行**不相邻**。

- 范围外的字幕可以读，用来理解代词指代、条件从句的起始、某个简称在全场语境里指什么。但**不要**基于范围外的内容给「{topic_name}」新增观点或投资机会条目。

- **铁律 B（不超）**：`投资机会` 数组中每个条目的 `标题` 字段必须严格满足以下任一：
  - 等于本主题名 `{topic_name}` 自身。
  - 等于【本主题子项白名单】里的某一项。
  - **不允许**凭世界知识自由判断"属于本主题"——子项白名单是上游已确定的归属，必须严格依据它。

  - 多个子项观点 → 每个子项一个独立 `投资机会` 条目，标题为单一资产名。
  - 只对整体有观点 → 标题就用 `{topic_name}`。

- **不得丢弃任何与「{topic_name}」主题或其子项相关的字幕信息**：不属于 `投资机会` 的内容必须按上表归入 `市场知识 / 事件与资产 / 其他`。仅当某段内容**完全无关**（直播带货、广告、抽奖、闲聊、节目互动）或属于**通用交易知识**（由交易技巧阶段统一负责，本任务不收录）时才可舍弃。
- 注意：本约束**仅针对 `投资机会` 数组**。`事件与资产 / 市场知识 / 其他` 字段允许提及子项白名单外的资产作为客观事实记录。

【跨主题事件不重复展开】
`[ROWID]` 范围内若包含一段**完整事件叙事**，且该事件的行号区间在上游聚类中已归属另一个主题（对照 `[DATABASE]` 的【其他主题的引用区间】——某主题的引用区间与本主题 `[ROWID]` 重叠时，重叠部分的事件主干归那个主题），则：
- **不得**在本主题的 `事件与资产` 中把该事件作为一个独立事件条目重复展开——同一事件只在其归属主题下完整叙述一处；
- 本主题资产在该事件中仅作为被提及、被影响或作例子的对象出现时，可在 `市场知识` 用一句话带过（如一句客观数据），**不**重复叙述事件的起因、发展、升级与定性；
- 判别依据：该事件的核心主语/主干是否属于其他主题，而非本主题或本主题的子项；被提及不等于事件主干。

【事件类主题规则】
若本主题是一个**事件**（政策出台/制裁或关税/监管行动/经贸冲突等，主题名是事件名而非资产名）：`投资机会` 只需保留一条主题名条目（短线/中长线观点标 `未表态 🤐`，不虚构方向）；事件的**客观进程**（起因→发展→升级→反制/反击→客观结果/客观定性）**完整**写入 `事件与资产`（可多条，按事件阶段展开），被提及/受影响的资产写进条目的 `涉及资产` 与 `市场知识`——事件主题不得把事件当资产给方向性观点，也不得因涉及资产不在白名单就丢弃事件内容。
- **主讲人的主观评价不属于事件（极重要）**：主讲人对该事件、其当事方行为或其涉及资产的主观评价、回应、判断、主张、情绪（如"觉得影响不大""自取其辱""主张直接反制"等）**一律不得**写入 `事件与资产`，必须写入 `观点` 字段（`标的名称` 填本主题名，即事件名）。`事件与资产` 记「发生了什么」、`观点` 记「主讲人怎么评」——即使标题写成「主讲人评价/回应 XXX」也不得入 `事件与资产`。

【任务与输出】
你需要根据以上输入和下述规则，从字幕中提取结构化的金融分析数据，并将结果填入指定 JSON 结构的对应字段中。最终只输出该 JSON 对象。

【规则冲突的裁决顺序】
下面的规则很多，个别场景下会互相牵制（例如"白名单每项必出条目"与"引用必须真实支撑"）。遇到冲突时按此优先级取舍，**按序裁决后直接输出，不要反复权衡同一个问题**：

1. **可溯源优先**：引用必须真实存在且能支撑该结论。宁可把观点标 `未表态 🤐`、把无支撑的字段留空，也不要为了凑格式而编造引用或内容。
2. **立场准确其次**：宁可 `未表态`，不要推断出主讲人没表达过的方向。
3. **覆盖完整性最后**：铁律 A（白名单每项必出）在前两条满足的前提下执行——某子项确实全场只被提及、无任何评价时，仍按铁律 A 输出条目，但观点标 `未表态 🤐`、`引用` 留**空数组 `[]`** 或填提及该资产的行号，两者都不算违规。

【字段提取规则】
1. 投资机会
   - 覆盖条件（满足任一即可）：给出明确操作建议、给出方向性判断、分析资产基本面并形成观点。
   - 时间定义：短线（未来几天至几周）；中长线（未来几个月至几年）。
   - 只写观点和操作建议，不重述客观事实。
   - 标题归属：每个条目的 `标题` 必须是属于「{topic_name}」的金融资产或「{topic_name}」板块本身，详见上文【当前主题约束】。即便字幕切片中提到了其他板块或资产（这是因引用区间重叠导致的，符合设计），也不得在此输出；这些内容应按【当前主题约束】中的归属表写入 `市场知识` 或 `事件与资产`，不可丢弃。
   - `观点` 取值必须严格为以下四种之一，不得有任何其他表述：
     * `"看多 🐂📈"`：主讲人对该资产/板块的方向性表达偏多。
     * `"看空 🐻📉"`：主讲人对该资产/板块的方向性表达偏空。
     * `"中性 🦀➡️"`：主讲人**明确**表达了多空交织、震荡、横盘、机构分歧等中性立场，且必须有字幕原文支撑。
     * `"未表态 🤐"`：主讲人在字幕中提及了该资产，但未给出任何方向性立场（仅在客观陈述事实/产业链/事件时提到）。
   - 中性 vs 未表态的判别（严禁混淆，违反将被视为编造立场）：
     * "中性"：主讲人**明确**说过震荡、横盘、多空交织、机构分歧等态度，`引用` 必须指向支撑该判断的原文。
     * "未表态"：主讲人没有方向性表达，仅作为客观提及。
     * 严禁因主讲人没明确表态就标"中性"——这是 AI 推断立场，违反"无幻觉"原则。当不确定时一律标"未表态"。
   - **条件/假设性表述判别铁律（极重要，违反将被视为编造立场）**：
     * 含 `如果`、`假如`、`万一`、`要是`、`可能`、`也许`、`大概率不会`、`不一定`、`要不然` 等条件/不确定词汇的语句，**只要主讲人没在条件成立分支里给出明确多空方向**，就一律标 `未表态 🤐`，**禁止**标 `看多`/`看空`/`中性`。
     * **重要补充**：若主讲人**在条件分支里明确给出了方向或操作建议**（如"如果回调了可以考虑"="等回调入场"=看多；"如果再涨就要小心"="减仓"=看空；"要是放量了就上"="加仓"=看多），**应当**按方向性观点标 `看多`/`看空`，**不**标"未表态"——条件铁律是为了防止把"如果X会怎样"的纯假设当成方向判断，不是为了把所有含"如果"的句子一刀切成未表态。
     * 典型反例（必须标"未表态"）：
       - "**如果**机器人行情继续的话，有可能把机器人非特斯拉部分讲一下" → 主讲人在罗列下次直播选题，并非预测机器人。
       - "然后**如果说**这个昇腾啊**又有戏了**，我们把昇腾后半部分给大家补一下" → 主讲人在用条件方式讨论选题、表达不确定，并非看多昇腾。
       - "万一AI算力起来了我就讲AI算力" → 假设性语句，未表态。
     * 反向反例（必须标方向性观点，不得标未表态）：
       - "风电我觉得**如果回调了之后是可以考虑的**" → 条件分支里给出了"可以考虑"的明确买入建议，标 `看多`（中长线）。
       - "**如果跌到XX我就买**" → 条件分支里给出了买入操作，标 `看多`。
       - "**要是再涨就要减仓**" → 条件分支里给出了减仓操作，标 `看空`。
     * 当出现这类条件/假设语句时，`逻辑` 字段必须显式说明这是条件性提及/选题罗列/不确定预期，而不是方向性观点。例如：
       - "主讲人在罗列下次直播备选选题，未对该资产给出方向性观点。"
       - "主讲人以'如果...'条件假设方式提及，未给出确定方向。"
     * 此规则优先级最高：即使其他段落出现该资产的方向性讨论，也**只能**对那些非条件性段落标多空，条件段落必须独立成一条引用并标"未表态"。
   - `短线` 与 `中长线` 字段处理规则：
     * 若主讲人对该时间维度有方向性观点（看多/看空/明确中性），按观点写入。
     * 若主讲人未对该时间维度表态，**仍须保留该字段**，将 `观点` 设为 `"未表态 🤐"`，`逻辑` 字段写"主讲人未在字幕中明确表态"或留空字符串，`引用` **可以是空数组 `[]`**——"未表态"是否定性结论，不需要举证；若手边正好有提及该资产的行号，填上也可以，但**不要**为了凑非空引用去挑与该资产无关的行。
     * 不得直接省略 `短线` 或 `中长线` 字段——总结要求每个时间维度上的立场都必须明示，省略会被视为信息丢失。
     * **时间维度独立性铁律（极重要）**：`短线` 与 `中长线` 的 `观点` 必须由**各自时间维度的方向性原话**直接支撑——
       - 若主讲人只说了一句涉及短期（如"周五跌得厉害"、"今天放量"），即便该句被某些读者视为暗示长期走弱，也**不得**用它支撑中长线立场；中长线必须另寻方向性原话，找不到就 `未表态 🤐`。
       - 若主讲人只说了"这板块完了"、"这趋势走完了"（中长期判断），不得据此倒推短线立场；短线必须另寻方向性原话或操作建议（如"不能着急"、"等回调"），找不到就 `未表态 🤐`。
       - 同一引用区间不能同时被填进 `短线.引用` 和 `中长线.引用` 然后标相同**方向性**立场（看多/看空/中性）——这等于把单条证据复制成两条。若只有一条方向性原话，只能支撑它所对应的那个时间维度。
       - **例外（明确允许，不要在此纠结）**：主讲人对该资产完全没有方向性表达时，`短线` 与 `中长线` 都标 `未表态 🤐`，两者 `引用` 都留空数组、或共用同一段"提及该资产"的引用，**都是正确做法**——本条禁止的只是"同证据支撑两个相同的方向性立场"。
   - `逻辑` 字段应总结主讲人给出的判断理由，可参照以下常见理由类型，但必须基于字幕原文：
     【短期看多理由示例】
       利好消息刺激（财报超预期、产品发布、中标大单、专利获批等）、技术形态突破（放量突破压力位、金叉等）、资金流入（北向/主力连续净买入）、事件驱动（纳入指数、回购）、情绪修复（超跌反弹）。
     【短期看空理由示例】
       利空事件（业绩不及预期、诉讼、减持、监管问询）、技术破位（跌破支撑、放量下跌、死叉）、资金流出（主力/北向连续净卖出、大宗折价）、解禁压力、市场情绪退潮。
     【短期中性理由示例】
       多空交织、等待催化（如财报公布前）、技术横盘（窄幅震荡、缩量）、消息真空期、机构分歧。
     【中长期看多理由示例】
       强劲基本面（营收/利润持续增长、高ROE）、行业景气向上（成长赛道、政策支持）、竞争壁垒（护城河）、估值合理偏低（低PE/PB、PEG<1）、管理层优秀、市场地位提升。
     【中长期看空理由示例】
       基本面恶化（营收/利润下滑、高负债）、行业衰退（夕阳产业、被颠覆）、竞争劣势（份额流失、价格战）、估值过高（透支未来业绩）、治理问题（财务造假、关联交易）、宏观政策利空（监管趋严、补贴退坡）。
     【中长期中性理由示例】
       稳定但缺乏增长（公用事业）、估值合理但无催化剂、转型观察期、多空因素长期并存、外部环境模糊。
   - `当前价格` 字段（**仅适用**于【本主题子项白名单中的个股清单】列出的个股；板块/事件主题或非个股子项**禁止**输出该字段）：
     * `观点` 取值严格为以下四种之一：
       - `"贵 💰"`：主讲人明确表达该个股**估值偏高 / 股价偏高 / 泡沫 / 透支未来 / 太贵了**等含义。
       - `"便宜 💸"`：主讲人明确表达该个股**估值偏低 / 低估 / 便宜 / 性价比高 / 跌出价值**等含义。
       - `"不贵也不便宜 ⚖️"`：主讲人明确表达该个股**估值合理 / 不算贵也不算便宜 / 估值正常**。
       - `"未表态 🤐"`：主讲人**未在字幕中**对该个股的当前估值/价格水平给出任何表态（默认值）。
     * 与短线/中长线观点**正交独立**——多空是方向性，价格是估值水平。完全可能"看多但当前价格贵 → 等回调再上"，也可能"看空但当前价格便宜 → 公司基本面变差"。请独立判别。
     * 仅基于字幕原文，**严禁**引入外部估值数据（PE/PB/市值等具体数字主讲人没说就不能补充）。
     * `引用` 规则——与 `短线`/`中长线` 的引用规则完全一致：
       - `观点` 为 `贵 / 便宜 / 不贵也不便宜` 时**必须**配非空 `引用`，且每个区间覆盖的字幕原文必须能直接支撑该价格标签、包含主讲人对该个股估值/价格水平的原话。
       - `观点` 为 `未表态 🤐` 时 `引用` **可以是空数组 `[]`**（同短线/中长线的未表态口径）——不需要举证"没表态"，也不要为凑引用挑无关行。
       - `逻辑` 支持：主讲人对估值的原话依据可在 `中长线.逻辑` 字段一并简述。
   - 无任何投资机会时返回 `[]`。

2. 个人交易记录
   - 提取主讲人已执行的个人买卖操作，包含标的名称、操作描述、操作理由、操作结果。
   - 若出现"还没有涨起来的"、"还没有反应出来的"、"这能说吗"等涉及个人交易的表述，须完整记录。
   - 无个人交易记录时返回 `[]`。

3. 事件与资产
   - 事件指字幕中明确提及的、与主题相关的**客观事实**，包括已发生/正发生事项、已披露计划、当前盘面异动。
   - **关键词事件子项**：若 `[TASK]` 块给出【本主题子项中的关键词事件】清单，这些是上游已降级为普通子项的事件（不再单列主题），其完整事件叙事（起因→发展→影响→结果）**必须**写入本字段（可多条，按事件阶段展开），被提及/受影响的资产写进 `涉及资产`；**不得**把它们作为 `投资机会` 条目的 `标题` 输出。
   - 排除纯假设或推演、未来走势判断、历史案例回顾。
   - **严禁收录主讲人的主观评价/回应/判断/主张/情绪（极重要）**：本字段只收**客观事件**（已发生/正发生事项、盘面异动、已披露计划）。主讲人"觉得影响不大""认为怂的可能性比较大""主张直接反制""称其行为自取其辱"等主观表述**不是事件**，一律不得写入本字段——这类内容写入 `观点`（见第 6 条）。`依据类型` 三选一只用于描述客观事件本身的性质（事实数据/逻辑推演/情绪比喻），不改变「本字段只收客观事实」的前提。
   - **去重铁律（极重要）**：同一事实的同一表述目的只出现在一个字段。涉及子项白名单资产的**客观事件**（已发生/正发生事项、盘面异动、已披露计划）**必须**录入 `事件与资产`，侧重事件本身（起因→发展→影响→结果）与受影响资产；主讲人的方向性判断归 `投资机会`、直接评价归 `观点`，侧重主讲人怎么判断/评价。二者可引用同一段字幕——`事件与资产` 记「发生了什么」、`观点` 记「主讲人怎么评」，不算重复。仅当某事实**纯粹作为评价的论证材料、本身不构成独立事件**（纯数据对比、纯逻辑推演，没有「发生了某事」）时，才不重复录入 `事件与资产`。
   - `依据类型` 三选一：`"事实数据"`、`"逻辑推演"`、`"情绪比喻"`。
   - 无相关事件时返回 `[]`。

4. 市场知识
   - 定义：与**本主题及其子项专有相关**的客观事实性知识——离开本主题语境即失去意义的知识（本板块特有信号、本行业专有产业链逻辑与技术原理等），与大盘无关，不构成直接操作建议。
   - 包括本主题专有的行业通识、产业链逻辑、技术原理、对主题或板块名称的解释、特定技术信号等。
   - 若出现"还没有涨起来的"等与市场知识相关的内容，须完整记录。内容必须客观，不夹杂观点或建议。
   - 与大盘或通用交易相关的内容（期权/期货操作机制、仓位管理、技术指标原理等对任何标的都适用的通用知识），即使在本主题上下文中被主讲人提及，也**不写入**本任务任何字段——它们由交易技巧阶段统一负责，本任务不重复收录。
   - 无市场知识时返回 `[]`。

5. 其他
   - 收录条件（满足任一即可，且必须同时不属于前四类）：
     (1) 内容与「{topic_name}」主题本身或其相关标的/资产（板块本身、属于该板块的个股、ETF、衍生品、相关大宗商品、产业链上下游等）有关；
     (2) **作为本主题资产的对照/反衬/类比出现的其他资产戏称或对比表述**——即使被对照的资产本身属于其他主题，只要主讲人是用它来反衬/类比本主题资产，就归入本主题的「其他」。`内容` 字段须明确标注这是对照/反衬表述，并写清被对比的本主题资产是谁。
       * 例：分析「半导体」时主讲人说"顿时觉得**酱香科技**不香了，**工行科技、农行科技**你怎么着也比不了**长鑫科技**啊"——这是用茅台/工行/农行的戏称来反衬长鑫科技利润高，应收录到「半导体」的「其他」，`内容` 写"用酱香科技/工行科技/农行科技反衬长鑫科技利润之高"。
   - **严禁**收录下列内容：
     * 直播带货、广告口播、抽奖互动、商品促销总结。
     * 与金融市场无关的闲聊、主播个人生活、节目互动调侃。
     * 其他主题的**独立讨论**（非对照/反衬，且与本主题资产毫无关联）——这些会由那个主题的分析任务负责。
   - 判别口诀：若该段内容既不涉及本主题、也不是为本主题资产做对照/反衬，则**直接舍弃**，不写入 `其他`。
   - 无相关内容时返回 `[]`。

6. 观点
   - 定义：主讲人对该标的的**直接口头评价**——即主讲人怎么"说"这个标的（含正面/负面/中性评价与"没有明确利空"这类非方向性点评），是**评价原意的忠实概括**，**不是**方向性判断或操作建议。
   - 与 `投资机会` 严格分工：方向性多空判断仍只由 `短线`/`中长线` 的枚举承担；`观点` 禁止把评价转写成多空（"没有明确的利空消息"不得写成"看多"），也禁止 AI 推断主讲人未说的态度。
   - **立场覆盖去重铁律（极重要）**：若某条直接口头评价的**全部内容**已被同标的 `投资机会` 条目的 `短线.逻辑` 或 `中长线.逻辑` 完整覆盖（同义表述也算覆盖），则**不得**再写入 `观点`——立场行与观点行重复出现同一句话属于观点冗余。只写立场逻辑**未覆盖**的独立评价；评价内容超出立场逻辑时只写超出部分。仅当该时间维度的立场为 看多/看空/中性 时，其 `逻辑` 才算立场行的承载——立场为 `未表态 🤐` 时 `逻辑` 只是过程描述，被其覆盖的评价**仍须写入 `观点`**（否则该信息在总结中彻底消失）。
   - 归属铁律：**子项白名单内标的**的直接口头评价必须写入 `观点`，**不得只写入 `市场知识`**；`市场知识` 仅保留纯客观事实知识（产业数据、技术原理、事件描述）。若评价与事实混在同一段，事实留 `市场知识`、评价写入 `观点`，两处不得互相替代。
   - **评价主体一致性铁律**：`观点` 必须是对 `标的名称` 所指标的**本身**的直接口头评价——句子的评价对象必须与 `标的名称` 一致。介绍板块/产业链客观结构的陈述（哪个子板块更核心、谁是谁的上游等）属于客观事实，一律归 `市场知识`；若一句话实际评价的是**另一个**标的，只允许挂在该标的名下输出，不得写成对本标的的观点（与"事实留 `市场知识`、评价归被评价标的"同规则拆分）。
   - `标的名称` 必须严格等于 `{topic_name}` 或【本主题子项白名单】里的某一项（同铁律 B，不允许凭世界知识自由判断）。
   - **事件主题的归属补充（极重要）**：若本主题是事件（主题名是事件名），主讲人对该事件、其当事方行为或其涉及资产的主观评价/回应/判断（如"觉得影响不大""自取其辱""主张直接反制"）同样写入 `观点`，`标的名称` 填本主题名（事件名）——事件主题通常无子项白名单，主题名就是合法的 `标的名称`。这类评价（主讲人怎么评）**不得**写进 `事件与资产`（那里只记事件客观进程）。
   - 同一标的可有多条评价 → 多个条目，每条评价配各自的 `引用`；主讲人未对该主题任何标的给出评价时返回 `[]`。
   - **观点原子化铁律（极重要）**：每条 `观点` 只表达**一个**独立评价，严禁用分号（；或 ;）把两件独立的事合并进一条。主讲人对同一标的给出多个评价时，**逐条拆成多个条目**，每条配支持该条评价的 `引用`（引用区间允许重叠）；每条独立走 `因果链` 规则——只写支持该条评价的论证，无论证则 `因果链=[]`。合并多条评价的"A；B"式条目视为格式错误。`投资机会` 的 `短线.逻辑`/`中长线.逻辑` 同样**禁止用分号把两件独立的事并成一段**——独立判断用句号写成完整句子，或按归属铁律拆到相应字段（独立评价入 `观点`）。
   - `引用` 行号必须落在 `[ROWID]` 范围内，区间内的字幕原文必须包含该评价原话（引用扩展规则同样适用）。
   - **因果链**：把主讲人形成该评价的完整论证拆成环节，按 `前提/事实` → `推理` → `结论` 顺序排列，**必须以 `结论` 环节收尾**；只罗列数字/事件而不给结论的论证无效（此时该内容不算论证，不得写入因果链）。
     * `前提/事实`：字幕中的事实、数据、观察（因）；
     * `推理`：主讲人如何从前提推到结论（可有可无，主讲人直接给结论时可省略）；
     * `结论`：主讲人的主张句。
   - **论点完整性铁律（极重要）**：结论标记词（`所以说`、`因此`、`所以`、`问题在这儿了`、`大家要理解`、`你要注意`、`你要挑选`…）引导的主张必须作为某条 `结论` 环节输出；大前提+小前提+结论式论证（如"软件跟硬件是对手盘…但是今天硬件涨软件也涨…这行情你咋做呀"→ 结论"根本动不了"）、举例式论证（如"拿存储为例…抄底就套死"→ 论点"难做"）、数据对比式论证（市盈率对比 → "要挑选合适的科技"）都必须完整入链——例子/数据作 `前提/事实` 环节、服务的论点作 `结论` 环节。
   - **论证完整性铁律（极重要）**：主讲人对同一现象的一句连贯评价（大前提 → 结论）必须作为**一个**观点条目输出，完整论证写入该条目的 `因果链`；**严禁**把 `因果链` 的「结论」环节再单独拆成一条只有结论、`因果链=[]` 的观点——这会让同一结论在报告中出现两次（一次带前提、一次裸结论）。已入某条 `因果链` 的结论，不得再作为独立观点条目输出。
   - **论证链归属**：因果链挂在**结论主体**（结论主语所指的标的，即本条目 `标的名称`）之下；对照资产只在环节内容里出现，不作为条目主体。
   - **对比论证归属规则（防张冠李戴）**：每个数字/比较词放回引用原文确认紧邻主语——"英伟达涨了那么多…30多倍"的主语是英伟达；"科创50平均市盈率200倍…我们经过7月份的下跌，还比人家海力士三星贵10倍"的"贵10倍"主语是"我们（科创50）"，**严禁**安到英伟达头上；主语不确定时该环节只保留无争议部分，删掉比较结论。
   - **对照提及资产的因果方向**：白名单外资产 A 作为论证本主题标的的对照出现时，A 只能作为 `前提/事实` 环节（以 A 为主语的事实）；`结论` 环节必须归本主题标的，严禁把本主题标的的结论写成 A 的结论，也严禁反推"A 强所以 B 弱"。
   - 主讲人只给裸评价、无论证时 `因果链=[]`（条目级 `引用` 仍必填）；每个环节的 `引用` 非空、落在 `[ROWID]` 内，区间原文必须能直接支撑该环节 `内容`（引用扩展规则同样适用）。

【本阶段的引用区间扩展规则】
引用的基本通则见 system prompt。本阶段在此之上追加以下扩展要求——目的是让读者脱离字幕也能读懂引用片段。

- **上下文完整性**：
  - 对于指代不明的内容（如"这样的标的"），必须包含前文明确提及该标的/公司名称的行。
  - 对于对比性内容（如"买H还是买A"），必须包含对比对象的明确说明。
- **主动扩展**：在选定的核心支撑行基础上，**主动**向前向后扫描相邻行，把以下内容一并纳入区间：
  * 任何条件标记词（`如果`、`假如`、`万一`、`要是`、`可能`、`也许`、`大概率`、`不一定`）所在的从句开头。
  * 让该资产名称首次明确出现的句子（如果核心行用了代词或上下文指代）。
  * 主讲人对该陈述给出"补充/否定/转折"的下一句（含 `不过`、`但是`、`其实`、`所以`）。
  * 该话题的开端句（如"我们说X"、"接下来讲X"），让读者知道讨论从哪里开始。
- **黑话识别扩展**：`[DATA]` 的内联注释（`词（正式名，类型）`）是逐行消歧结论——若某行内联注释的 `正式名` 等于「{topic_name}」，那么该行就是「{topic_name}」的引用候选——必须把它纳入引用区间检索范围，不能因为字面与白话主题名不一致而漏掉（典型例子：主题是"大唐发电"、字幕里说"大唐"，`[DATA]` 里写作 `大唐（大唐发电，股票）`，应当把该行视为本主题引用）。`[ANNOTATION]` 的 `关键词` 只补充无法内联的单字别名（如「光」→「光模块」）。
- **扩展终点**：遇到下列断点之一立即停下：
  ① 主讲人切换到不相关话题；
  ② 出现"我们看下一个"、"下一个我们讲"、"切回到 X"、"接下来"、"再讲讲"、"然后我们" 等显式分段标志；
  ③ 单次扩展超过 8 行（硬上限）。
- **罗列性语句铁律**：对于"如果A...如果B...如果C..."这种枚举（典型场景：主讲人在讨论下次直播选题、列举假设情形），**必须**把整个枚举段作为一个引用区间，而不是只截其中一个分支——这能让读者一眼看出"主讲人在罗列选项"而非"主讲人在预测某个具体方向"。

【特别强调】
- 对于【本主题子项白名单】中列出的**每一个**"子项"，都必须在输出中体现，按内容归入上述五个字段之一，不得遗漏。
- 若同一个股在字幕多处出现，须整合所有相关上下文进行分析。
- 所有六个顶级字段（`投资机会`、`个人交易记录`、`事件与资产`、`市场知识`、`观点`、`其他`）必须存在，无内容时为空数组 `[]`。
- 资产全覆盖（HR2 全面性铁律）：本主题在字幕中提及的每一个属于「{topic_name}」的资产（板块本身、子项白名单中的"子项"、字幕中明确提到的属于本板块的具体资产），都**必须**在 `投资机会` 数组中至少出现一次。
  * 若主讲人对该资产在某时间维度有方向性观点，按观点写入。
  * 若主讲人未表态，按上文规则在 `短线` 与 `中长线` 中将 `观点` 设为 `"未表态 🤐"`，`引用` 可留空数组 `[]`。
  * 该约束保证速览层面不丢任何字幕中出现的本主题资产。仅在 `事件与资产` 或 `市场知识` 中提及而不在 `投资机会` 中出现，会导致下游速览渲染丢失该资产。

【输出前自查清单】
以下只用来**抽查你自己感到不确定的条目**，不必逐条对全量输出重跑一遍。六个顶级字段是否齐全、空数组填写、引用行号是否越出本主题行号范围等形式问题由系统代码兜底（缺字段与越界引用会被自动补齐/过滤），**不用你检查**。

1. 检查每一条 `投资机会.短线` 与 `投资机会.中长线` 的 `引用` 区间内的字幕原文：
   - 是否存在 `如果`、`假如`、`万一`、`要是`、`可能`、`也许`、`大概率不会`、`不一定` 等不确定词汇却被标成 `看多`/`看空`/`中性`？若有，必须改成 `未表态 🤐`，并在 `逻辑` 中说明这是条件性提及。
2. 每一条引用区间是否涵盖完整语境？
   - 是否截取了"如果X，那么Y"中的"Y"却漏掉了"如果X"？若有，向前扩展把"如果X"包进来。
   - 是否截取了一个孤立的代词句却没有该资产名称首次出现的句子？若有，向前扩展。
3. 是否存在"罗列性语句"（如主讲人在讨论下次直播选题、列举多个假设情形）被错误地拆成了多个独立看多/看空条目？若有，合并为一个引用区间并标 `未表态`。
4. 是否扫过 `[DATA]` 的内联注释（`词（正式名，类型）`）与 `[ANNOTATION]` 的「关键词」，把 `正式名` 等于「{topic_name}」的别名行（`词`≠`正式名`）纳入了引用？是否漏掉了"大唐"（=大唐发电）/"SST"（=固态变压器）这类消歧后的黑话行？若有遗漏必须补回引用。
5. 是否每个 `投资机会` 条目的 `标题` 都严格等于 `{topic_name}` 或【本主题子项白名单】里的项？若有"凭世界知识判断属于本主题"的标题（典型如分析「人工智能」时把 `燧原科技` 当投资机会），必须删除（其内容降级到 `市场知识`）。
6. 子项白名单里**每一项**是否都至少作为一个 `投资机会` 条目的标题出现？没有方向性观点时仍要保留，`观点 = "未表态 🤐"`。
7. 对【本主题子项白名单中的个股清单】里的**每一项**（若该块存在），是否都输出了 `当前价格` 对象（含 `观点` 和 `引用`）？其 `引用` 是否非空？板块/事件条目（不在个股清单里）是否**未**输出 `当前价格` 字段？
8. 对每一条 `投资机会` 中标了 `看多 / 看空 / 中性` 的 `短线` 或 `中长线`：检查其 `引用` 区间内的字幕原文是否包含**对未来方向的判断**或**操作建议**。若只有过去式事实陈述（如"跌得厉害"、"涨了多少"、"今天放量"），必须改为 `未表态 🤐`，并把该事实搬到 `事件与资产`。
   - **反向自查（同等重要）**：扫描 `市场知识` 与 `事件与资产` 中是否存在含**操作建议词**的句子（"可以考虑"、"等回调"、"不能着急"、"赶紧上"、"再等等"、"建议买"、"建议卖"、"减仓"、"加仓"），或含**方向性预判词**的句子（"会涨"、"会跌"、"要起来了"、"要见顶"、"要走完了"）。若有，必须**升级**为 `投资机会` 条目（按"事实陈述 vs 方向性观点 铁律"反例 3、4 处理），不得只放在 `市场知识`。典型例子："风电如果回调了可以考虑"应在 `投资机会` 中标 `看多 🐂📈`，不是只写进 `市场知识.内容`。
9. 检查同一资产的 `短线.引用` 与 `中长线.引用` 是否使用了**完全相同的引用区间**支撑相同立场。若有，必须保留方向性原话所属的那一时间维度（短线证据→短线，中长期证据→中长线），另一维度改 `未表态 🤐`。
10. 对每一条 `事件与资产.影响与结果`、`事件与资产.逻辑`、`市场知识.内容`：把每个具体动词、名词、形容词逐个回到引用区间字幕原文里检索字符串，若找不到逐字对应（包括同义改写、添加修饰词），必须删除该词或换成字幕原词。重点核查"抄底/见顶/暴跌/反弹/见底/已结束/趋势终结/周期见顶/重挫/跳水"这类常见 LLM 加工词。
11. 白名单内标的的主讲人评价是否都写入了 `观点`？每条 `观点.观点` 是否只记录主讲人评价原意、未做方向性推断（"没有明确的利空消息"不得写成"看多"）？每条 `观点.引用` 区间原文是否包含该评价原话（`引用` 非空）？`标的名称` 是否严格 ∈ `{topic_name}` 或白名单？
12. 扫描 `市场知识`：是否残留白名单内资产的口头评价（如"宁王没有明确的利空消息"）？若有，必须移入 `观点`，`市场知识` 只留客观事实。
13. 每条 `观点` 的 `因果链` 是否以 `结论` 环节收尾？是否只罗列数字/事件而不给结论（若是则无效）？每个数字/比较词的主语是否与引用原文一致（"贵10倍"的主语不得张冠李戴）？每环节 `引用` 是否非空且原文能支撑该环节 `内容`？
14. 涉及子项白名单资产的客观事件（已发生/正发生事项、盘面异动、已披露计划）是否都录入了 `事件与资产`？`事件与资产` 记「发生了什么」，`投资机会.逻辑` / `观点.因果链` 记「主讲人怎么判断/评价」，二者引用同一段字幕不算重复；只有纯粹作为评价论证材料、本身不构成独立事件的纯数据/纯推演，才不必重复录入 `事件与资产`。**反向自查（尤其事件主题）**：扫描 `事件与资产` 是否残留含「主讲人评价/回应/认为/觉得/主张/称」等主观表述的条目？若有，必须移入 `观点`（`标的名称` 填主题名），`事件与资产` 只留客观事件。
15. 扫描 `市场知识`：是否残留对任何标的都适用的通用交易机制（期权操作、仓位管理、技术指标原理等）？若有，必须删除（由交易技巧阶段负责）。

若任一答案为否，请重新检查并修正。
