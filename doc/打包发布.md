# 打包发布

把桌面 GUI 打包成单文件可执行程序，分发给没有 Python 环境的新手。打包产物默认**内置 PDF 能力**：优先调用系统自带 Edge/Chrome 无头模式生成 PDF（零额外安装），weasyprint 仅作回退。

## 依赖

`pyproject.toml` 的 `dependencies` 已默认包含全部依赖（PySide6、weasyprint、akshare、transformers、pyinstaller 等），`uv sync` 一把装齐，无需任何 `--extra` 选项。

## Windows 打包

在项目根目录执行（或双击）：

```bat
script\build_win.bat
```

脚本内部：

1. `script\setup_env.bat`——检查/安装 Python、uv、ffmpeg，并执行 `uv sync`（装齐全部依赖）。
2. `uv run pyinstaller --clean --noconfirm finance_video_summarizer.spec`——打包。

产物：`dist\finance-video-summarizer.exe`。

## macOS 打包

```bash
bash script/build_mac.sh
```

脚本内部：

1. `uv sync`。
2. `uv run pyinstaller --clean --noconfirm finance_video_summarizer.spec`。
3. `hdiutil` 把 `.app` 打成 `.dmg`。

产物：`dist/finance-video-summarizer.app` 与 `dist/财经视频总结.dmg`。

## 打包配置（finance_video_summarizer.spec）

- 自动收集 `src/` 下 prompt 模板（`.jinja2` / `.txt` / `.json`）、`database/`、`config/` 数据文件，打进 `_MEIPASS`，使源码里 `Path(__file__)` 相对路径在 frozen 下仍命中。
- 对 `weasyprint` 执行 `collect_all`，收集其数据文件与动态库（作为 PDF 回退路径）。
- `.env` **不打进**安装包：首次运行时 GUI 弹出设置页，填写密钥后写入 exe 旁边的 `.env`。
- `torch`、`pytest`、`tkinter` 不打进（体积 / 无用）。

## 注意事项

### PDF 生成方式（默认走系统浏览器，无需 GTK）

PDF 由 `rendering_controller._export_pdf` 生成，**优先**查找系统自带浏览器（Windows 的 Edge、或 Chrome/Chromium），用无头模式把 `summary.html` 打印成 PDF——Windows 10/11 都自带 Edge，因此**开箱即用、无需安装任何组件**。

找不到浏览器或命令失败时，才回退到 weasyprint。weasyprint 通过 cffi 绑定系统 GTK 库（cairo / pango / harfbuzz / fontconfig），`collect_all("weasyprint")` 只覆盖**包内**数据文件与动态库；**系统级 GTK DLL 可能仍需在打包机上额外收集**，否则这条回退路径会报「找不到 libcairo / libpango」。回退路径仅供极端场景（Edge 被卸载），一般无需处理。

### 体积

GUI 打包包含 PySide6（主体积）+ weasyprint 回退依赖，单文件体积较大（数百 MB），属预期。
