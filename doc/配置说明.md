# 配置说明

项目配置分三处：`config/`（模型与管线参数 + 待总结链接）、`.env`（API 密钥）、`database/`（金融领域知识库）。

## 1. `config/llm_config.json`（LLM 与管线参数）

| 字段 | 作用 |
|---|---|
| `_说明` | 人类可读说明：模型厂商（DeepSeek）/ 模型 / 用途 / 申请与文档链接（代码忽略此字段） |
| `default_profile` | 默认 profile 名（`deepseek-v4-flash`） |
| `profiles` | LLM 模型定义：`provider` / `model` / `base_url` / `api_key_env` / `thinking` / `reasoning_effort` / `temperature` / `max_tokens` / `usage_map` / `kv_user_id` |
| `stages` | 各阶段（键形如 `N_M`）的 `reasoning_effort` 覆盖，精确 > 通配 > 全局 `*` |
| `llm_batch` | 每步每次调用处理的工作单元数上限（如 `2_1_粗筛`、`7_1_主题分析`） |
| `llm_group_count` | 分组并行组数（4_4 / 4_7 候选粗筛） |
| `embedding_dedup` | 向量主题去重相似度阈值（默认 0.6） |
| `embedding_recall` | 候选父 embedding 召回相似度阈值（默认 0.5） |

缺失 / 损坏 / 键缺失时回退内置默认值并打 WARNING，不中断管线。

## 2. `config/video_url.json`（待总结链接）

纯 URL 数组，支持 B 站 / YouTube / 抖音：

```json
[
  "https://www.bilibili.com/video/BV15NYu6vEP8/"
]
```

命令行**不带 `--url` 时默认总结这里的全部链接**；GUI 在界面里粘贴链接、不读此文件。

## 3. `.env`（API 密钥，不入库）

| 变量 | 作用 |
|---|---|
| `DEEPSEEK_API_KEY` | DeepSeek 大模型密钥（LLM） |
| `TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY` | 腾讯云密钥（ASR / COS） |
| `TENCENT_COS_BUCKET` / `TENCENT_COS_REGION` | COS 对象存储（音频中转） |
| `TENCENT_LLM_API_KEY` | 腾讯云 TokenHub embedding（主题去重） |
| `TENCENT_HOTWORD_ID` | 可选，ASR 热词表 ID |

GUI 首次启动的设置页会写回 `.env`；命令行用户从 `.env.example` 复制后填写。

## 4. `database/`（金融领域知识库）

| 文件 | 作用 |
|---|---|
| `hotwords.json` | 通用热词表 |
| `jargon_stock.json` / `jargon_sector.json` / `jargon_hotspot.json` | 个股 / 板块 / 热点黑话 → 正式名映射 |
| `root_sector.json` / `stock_sector.json` | 申万行业库 / 个股板块反查表 |
