# 费用说明

一次视频总结涉及三处计费。**只有 LLM 有本地费用报告**，ASR 与 embedding 本地不统计、需要去腾讯云控制台看账单。

## 1. LLM（DeepSeek，deepseek-v4-flash）

按 token 计费，分三档、峰谷价（单位：元 / 百万 token）：

| 计费项 | 高峰 | 空闲 |
|---|---|---|
| 输入（缓存命中） | 0.10 | 0.05 |
| 输入（缓存未命中） | 3.0 | 1.5 |
| 输出（思考 + 正文） | 9.0 | 4.5 |

- **高峰时段**：北京时间周一至周五 9:00–12:00、14:00–18:00；其余为空闲（半价）。
- **从哪看**：每次跑完，命令行会**自动打印完整费用报告**——按阶段（`1_1 话题分割`、`5_2 宏观分析`、`7_1 主题分析` 等）列出调用数、token 用量（命中 / 未命中 / 思考 / 正文）与费用。原始数据来自落盘日志 `summary_data/<平台>/<作者>/<标题>/llm_analysis/llm_output_*/round*__attempt*.json` 的「用量」字段。
- 价格表定义在 `src/summary_cost.py` 的 `PRICES`（`script/summary_cost.py` 仅为兼容旧导入的 re-export 薄壳）。

## 2. ASR（腾讯云语音识别）

- 按**音频时长**计费（录音文件识别，模型 `16k_zh_en_2.0`）。
- 本地不统计费用，**从哪看**：腾讯云控制台 → 费用中心账单（官网 https://cloud.tencent.com/product/asr）。
- 音频时长可参考：`summary_data/<视频目录>/recognize_subtitle/subtitle_tencent.txt` 最后一条的结束时间，或运行日志里的「时长校验: 源=xxx s」。

## 3. embedding（腾讯云 TokenHub）

- 按**调用 / token** 计费（模型 `kinfra-text-embedding-4b`，2560 维，用于第 4 步主题向量去重）。
- 本地不统计费用，**从哪看**：腾讯云控制台 → 费用中心账单。
