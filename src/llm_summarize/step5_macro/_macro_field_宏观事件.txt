{
  "宏观事件": [
    {
      "标题": "≤15字，概括该条因果链主题（如"美联储降息"）",
      "观点": "总结主讲人如何将宏观事件通过因果链条影响整体市场，聚焦"是什么驱动了市场"；按"事件→影响"逐条压缩概括，禁止逐句照抄字幕原文（数字、事件名、机构名保持原文写法）",
      "引用": [int, int, ...]
    }
  ]
}

【字段提取规则】
2. 宏观事件
   - 提取内容：外部**宏观事件**（政策、数据、海外、监管、影响**整体市场**的事件）及其如何传导至整体市场表现或风险偏好（果）的完整因果逻辑。
   - **作用域下界（硬约束，越界的条目会被系统删除）**：本字段只收影响**整体市场**的宏观事件。以下不属于本字段，一条都不要输出：
     * **板块级/产业级事件**（"刚果金禁令→铜价/铜矿板块"、"某厂商停产→光模块板块"、"FCC发证→光模块"）——这些是**板块事件**，由其他阶段负责，本字段不收；
     * 单一标的的个股事件——由其他阶段负责。
     判断口径：**这个事件传导到的是"整个市场/整体风险偏好"，还是"某个板块/某只股票"**？后者一律不输出。
   - 分块要求：每个独立的"宏观事件→市场影响"因果链一块（如"美联储降息→市场风险偏好回升"、"某国加征关税→整体避险"各一块），不同事件分开成块。
   - 「标题」：≤15 字，用事件名或影响主题概括（如"美联储降息"）。
   - 本场没有任何影响整体市场的宏观事件时，输出空数组 `[]`——不要为了填满字段而编造事件，或把板块事件/个股事件搬进来。宁可这个字段是空的，也不要装错内容。
   - 引用要求：每块引用必须同时包含本块的"宏观事件"和"对市场的影响"，使因果链完整可读。当主讲人转向后市预测或策略时，引用范围截止于因果链结束处，不向前扩展。块间引用不得共享行号。
