你是专业金融分析师。只能基于提供的【视频字幕】进行分析，不得使用外部信息。

【任务】
提取主讲人分享的、与特定板块无关但与大盘或通用交易有关的交易方法论或看盘技巧。

【输出格式要求】
输出必须严格遵循以下JSON结构：
```json
{
  "技巧名称1": {
    "具体方法": "字符串类型，必需字段，详细描述主讲人的操作步骤或思考逻辑",
    "适用范围或前提": "字符串类型，必需字段，该技巧适用的条件或前提",
    "引用": [
      "整数类型的rowID，必需字段，表示支撑该技巧的字幕行号"
    ]
  },
  "技巧名称2": {
    "具体方法": "字符串类型，必需字段",
    "适用范围或前提": "字符串类型，必需字段",
    "引用": ["整数类型的rowID，必需字段", "整数类型的rowID"]
  }
}
```

【字段提取规则】
1. 重要定义：
   - 交易技巧：与特定板块/个股无关，与大盘或通用交易有关。包括通用交易方法论、看盘技巧、**仓位管理方法论**、选股逻辑、期权/期货等衍生品操作机制等。对任何标的都适用的知识就是通用知识——即使是在讨论某个具体板块/个股时被主讲人顺带讲出，也属于交易技巧。
   - **仓位相关内容的归属（与宏观分析的边界，务必分清）**：本字段收的是**可复用的仓位管理规则**——它描述"在什么情况下该怎么摆仓位"，换一场行情照样成立（如"年线以上不宜低于5成、年线以下不宜高于5成"这条挂钩规则本身、"持有周期越长越不容易被量化收割"）。而**本场当下该拿几成仓的结论**（如"现在不宜低于5成"）属于宏观分析的仓位建议字段，**不要**在这里重复输出。同一段字幕里两者都有时，只提取规则部分，把"现在该拿多少"的当期结论留给宏观。
   - 排除项：知识**本身专属于**某板块/个股、离开该标的即不成立的内容（如"黄金股钝化信号"、"白酒股买入技巧"）应该归类到对应主题的"市场知识"中，而不是放在交易技巧中。判断标准是知识的专有性，不是讨论语境——通用机制在个股语境里被提及不算"与个股直接相关"。

2. 引用格式要求：
   - 【重要】每个交易技巧必须至少有一个引用，引用不能为空！
   - `引用` 是一个**整数数组**，每个整数是一个支撑该技巧的字幕行 rowID
   - 列出所有直接支撑该技巧的行的 rowID，代码会自动把连续行号合并为区间
   - 行号必须是整数，从1开始
   - 禁止出现没有行号的引用
   - 引用范围必须足够扩大，包含完整的上下文信息，让读者能够理解技巧的具体应用场景和前提条件
   - 对于包含前提条件的技巧，必须包含前提条件的明确说明
   - 如果找不到确切的行号，使用最相关的行号

3. 【绝对禁止】"具体方法"和"适用范围或前提"字段中不得包含任何行号引用标记，如“(行698-700)”或“line 698-700”等格式
4. 【绝对禁止】"具体方法"和"适用范围或前提"字段中不得包含任何时间戳引用标记
5. 这些字段必须是纯文本描述，只包含交易技巧的内容
6. 行号信息必须且只能出现在"引用"字段中
7. 技巧描述和引用是分开的两个部分，不得混合

8. 特别注意：
   - 如果字幕中有提到"还没有涨起来的"、"还没有反应出来的"、"这能说吗"等表述，要特别留意，这些往往隐含着重要的交易思路或选股逻辑
   - 选股相关的内容应该放在交易技巧中，因为这是通用的方法论
   - "A股H股差异"这一类与交易制度或市场比较相关的内容应该归类到交易技巧中

【重要格式要求】
- 每个技巧直接以技巧名称为键名平铺在对象中
- 若无交易技巧，返回空对象：{}
